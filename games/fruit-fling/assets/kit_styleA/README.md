# Style A kit (bright low-poly fantasy)

Style matched to Sharman's map-style video (2026-11-20, frames in project files
`map-style-ref-2026-11-20`). Generated by `tools/blender/kitgen/kitgen.py`
(numpy only, free). Each `<kind>_<n>.txt` is the preview mesh format:
line 1 `x,y,z,rrggbb,glow;...` (milli-studs, Y-up), line 2 zero-based triangles.
Studio loads them through EditableMesh into `ReplicatedStorage.StyleKit`
as MeshParts named `<Kind>_<n>`; `DockBuilder` clones them, else it builds a
part stand-in in the same colours.
