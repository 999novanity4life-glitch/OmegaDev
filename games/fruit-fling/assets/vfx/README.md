# VFX textures (2026-11-20)

Painted procedurally for fruit-fling (no third-party art): white with alpha,
tinted in game by the Color of the ParticleEmitter / Beam / ImageLabel.
Uploaded to Roblox with Sharman's OK; the asset ids live in Config.UI.Vfx.

| file | use |
|---|---|
| glow.png | soft aura puffs, light blooms |
| flare.png | 4-point star flare (ref M4), star bursts |
| twinkle.png | small sparkles |
| spark.png | streak sparks (use with Squash / velocity orientation) |
| ring.png | shockwave rings |
| ray.png | Beam texture for god rays, pillar, halos |
| wisp.png | energy wisps / smoke |
