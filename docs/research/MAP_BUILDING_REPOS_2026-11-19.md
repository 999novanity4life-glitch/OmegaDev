# Open-source repos for intentional AI map building (2026-11-19)

Asked by Sharman: the fruit-fling greybox (PR #28: flat water plane, distance lines, nothing else) is far too low quality. Find open repos that make AI map building **intelligent and intentional**: layout rules, procedural placement, prop scattering with intent, kits, lighting presets, Studio MCP build helpers.

Method: GitHub repo search (`gh api search/repositories`, ~27 queries), then README + LICENSE read from `raw.githubusercontent.com` for every repo below. Star counts and dates are from the search on 2026-11-19. Nothing here was installed or run yet. "Read" = I read the README/skill text; "Not run" = no Studio test.

## What none of these solve
No repo makes a map look **good** by itself. SyphoDev says it plainly: its prover passed 16 checks on a map made entirely of boxes. Looks come from (1) a reference board, (2) macro silhouettes and meshes, (3) lighting, (4) a blind screenshot review. That is why the rulebook pairs the repos with the video lessons Sharman is sending.
