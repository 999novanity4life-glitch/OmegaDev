# 02 The Core Loop

Fact: Roblox defines the core loop as minute-to-minute interaction + the most-repeated actions + a progression engine; without the engine games become "repetitive and shallow" ([core loops](https://create.roblox.com/docs/en-us/production/game-design/core-loops)).

Studio rules:
- Name the **core verb** in one word (ROLL, DIG, CLICK, FIGHT). Every screen serves it.
- The loop is 10–30 s: verb → reward → spend → stronger verb.
- Each loop must change something visible (bigger number, new zone, new pet).
- Meta loop over days: collection (index), rebirth/prestige, dailies, events.
- Social hook: something better with friends (raids, trading, party boosts). Co-play days are a discovery signal ([discovery](https://create.roblox.com/docs/discovery.md)).

## Party games (added 2026-10-23, see chapter 14)
- Round loop = LOBBY → INTERMISSION 15-20 s → ROUND (under ~2 min) → RESULTS 5-8 s. Devs use 15-35 s intermissions ([DevForum](https://devforum.roblox.com/t/ideal-intermission-time/724439/1)).
- The verb stays dumb-simple (touch to pass the bomb); depth comes from movement skill, which is what tops YouTube ([DevForum](https://devforum.roblox.com/t/feedbackproblem-hot-potato-slap-counter-game/4450393); [video, 1M views](https://youtu.be/WXfZdtVDB5w)).
- The 2026 breakouts pair a rising hazard with collect + rebirth (Escape Tsunami For Brainrots, 4-5M peak, [rotrends](https://rotrends.com/game/9363735110)).
