# 04 Progression and Economy

Studio rules (Balance owns these, proven with a Lune simulation):
- Write target times first: first upgrade < 1 min, first rare < 5 min, level 10 ≈ first session, each zone ≈ 1–2 sessions.
- Every currency has sources and sinks. Sinks grow with sources or inflation kills the goals.
- Costs scale faster than income per zone (e.g. ×1.5–2.5 per zone) so new zones feel needed; rebirth resets currency but multiplies income.
- Big numbers need short formats (1.2K, 3.4M, 5.6B) everywhere, same function.
- Offline/AFK rewards are capped so they help but don't replace play.
- All numbers in `Config.luau`, nowhere else.
